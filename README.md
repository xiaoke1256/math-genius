# 数学达人闯关游戏 / Math Genius Challenge Game

面向小学生的数学口算闯关小游戏（「数学闯关小达人」）。

A mental math challenge mini-game for elementary school students (*Math Challenge Genius*).

## 功能简介 / Features

- **选年级开局 / Grade selection**：支持 1–2、3–4、5–6 年级，可查看题型说明  
  Choose grades 1–2, 3–4, or 5–6; view question-type descriptions before starting.
- **闯关答题 / Level challenge**：限时四选一答题，共 20 关；含生命值（最多错 3 题）、连击与得分  
  Timed multiple-choice questions across 20 levels; includes lives (up to 3 wrong answers), combos, and scoring.
- **本地题库 / Local question bank**：按年级随机生成加减乘除等口算题，无需联网与登录  
  Randomly generates addition, subtraction, multiplication, and division problems by grade; no network or login required.
- **局末回顾 / End-of-game review**：统计得分与错题，支持错题查看  
  Summarizes score and wrong answers; review incorrect questions after each run.
- **其他 / Other**：关于、反馈吐槽等  
  About page, feedback, and more.

## 工程说明 / Project Structure

主代码在 `math_genius_uniapp/` 目录，使用 HBuilderX 或 uni-app CLI 开发与编译。

Main source code lives in `math_genius_uniapp/`. Develop and build with HBuilderX or the uni-app CLI.
