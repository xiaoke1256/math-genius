# 数学达人闯关游戏

面向小学生的数学口算闯关小游戏（「数学闯关小达人」）。

## 预览
<img src="https://github.com/xiaoke1256/math-genius/blob/main/doc/image/preview.png?raw=true" width="300">

## 功能简介

- **选年级开局**：支持 1–2、3–4、5–6 年级，可查看题型说明
- **闯关答题**：限时四选一答题，共 20 关；含生命值（最多错3题）、连击与得分
- **本地题库**：按年级随机生成加减乘除等口算题，无需联网与登录
- **局末回顾**：统计得分与错题，支持错题查看
- **其他**：关于、反馈吐槽等

## 工程说明

主代码在 `math_genius_uniapp/` 目录，使用 HBuilderX 或 uni-app CLI 开发与编译。
